# Contributing to MiraCommander

Thanks for your interest in MiraCommander, a dual-pane file manager built with Rust, Tauri 2, and TypeScript.

## How to help

- **Report bugs:** Open an issue describing your operating system, app version, steps to reproduce, expected behavior, and actual behavior.
- **Suggest improvements:** Explain the use case and why the feature would help.
- **Improve documentation:** Clarify setup instructions, keyboard shortcuts, or translations.
- **Submit code:** Open a focused pull request with a clear description and testing notes.

## Local development

Install Node.js and Rust, then follow the platform-specific dependencies in [README.md](README.md).

```bash
npm install
npm run tauri dev
```

For production builds:

```bash
npm run tauri build
```

## Pull request checklist

- [ ] Change is focused and explained.
- [ ] Relevant behavior has been tested.
- [ ] Documentation is updated when necessary.
- [ ] Screenshots are included for visual changes.
- [ ] No credentials, personal files, or generated build outputs are committed.

Please be respectful and constructive in issues and reviews.
